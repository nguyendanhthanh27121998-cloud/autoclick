# Auto Click (Samsung Z Fold 3)

1. Mở thư mục này bằng Android Studio (Hedgehog trở lên), chờ Gradle sync.
2. Bật Developer options + USB debugging trên Z Fold 3, cắm cáp, bấm Run.
   Hoặc: Build > Build APK(s) rồi copy file app-debug.apk sang máy để cài.
3. Mở app: cấp quyền hiển thị nổi -> bật dịch vụ trợ năng -> mở bảng điều khiển.
4. Kéo khung đỏ tới vùng cần click, chỉnh thời gian (ms), bấm "Bắt đầu".

Lưu ý: Samsung có thể hiện "Cài đặt hạn chế" khi bật trợ năng cho app cài ngoài Store:
Cài đặt > Ứng dụng > Auto Click > ⋮ > Cho phép cài đặt bị hạn chế.
